# Euryale-Tool-Changer
Line-Contact Kinematic Coupling fork of MedusaHC by Irbis3D

Euryale Tool Changer is an open-source Toolchanger project based on the MedusaHC Toolchanger by Irbis3D. This project is in its beta stage, where it is currently being developed.



High-load kinematic coupling implementation based on a modified Maxwell layout. This design replaces standard point-contact spheres with floating 6mm barrel bolts resting on parallel 3mm dowel pins, maximizing shear and transverse load capacity while maintaining positional repeatability.

Technical Overview
Kinematic couplings precisely locate two bodies relative to one another by constraining exactly 6 degrees of freedom (DOFs) without over-constraint.

Standard spherical kinematic mounts rely on point contact, making them susceptible to high Hertzian contact stresses under heavy shear or transverse loads. This design utilizes line contact via parallel dowel V-grooves paired with floating cylindrical barrel bolts.
